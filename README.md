# ระบบรับสมัครเรียนออนไลน์ (โควตา ๒๕๗๐)
## วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์
### สำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.)

เว็บแอปพลิเคชันระบบรับสมัครนักเรียน นักศึกษาใหม่ รอบโควตาพิเศษ ประจำปีการศึกษา ๒๕๗๐ พัฒนาขึ้นอย่างสมบูรณ์แบบเพื่อการใช้งานจริง แบ่งเป็น ๒ ส่วน คือ ส่วนผู้สมัคร (Public Portal) และส่วนเจ้าหน้าที่งานทะเบียน/ผู้บริหาร (Admin Portal) พร้อมระบบออกเอกสาร PDF ตรงตามแบบฟอร์มกระดาษราชการ ๑๐๐% และระบบส่งออกข้อมูล Excel มาตรฐาน ศธ.02

## 🌟 บัญชีและข้อมูลสำคัญสำหรับการทดสอบ (Credentials)

### ๑. การเข้าสู่ระบบฝั่งเจ้าหน้าที่ / ผู้ดูแลระบบ (/admin/login)
- **URL เข้าสู่ระบบ:** `http://localhost:3000/admin/login`
- **เลขประจำตัวประชาชน:** `11999`
- **รหัสผ่าน:** `090450`
- **บทบาท:** `super_admin` (นายประสิทธิ์ วงศ์สุวรรณ - ผู้ดูแลระบบงานรับสมัคร)
*(มีปุ่มคลิกเดียวเพื่อกรอกข้อมูลทดสอบอัตโนมัติบนหน้า Login)*

### ๒. ตัวอย่างข้อมูลผู้สมัครสำหรับทดสอบหน้า "ตรวจสอบสถานะ" (/status)
ในระบบมีข้อมูลตัวอย่างที่ Seed ไว้ ๓๐ รายการ ครอบคลุมทั้ง ๑๓ แผนกวิชา:
1. **สถานะ "ผ่านการคัดเลือก" (ปวช. ไฟฟ้ากำลัง):**
   - เลขบัตร ปชช.: `1100400123451` | วันเกิด: `14 พฤษภาคม 2553` (ดาวน์โหลดใบสมัคร PDF และใบมอบตัวได้)
2. **สถานะ "มอบตัวแล้ว" (ปวส. สายตรง ไฟฟ้ากำลัง):**
   - เลขบัตร ปชช.: `1100400123452` | วันเกิด: `20 สิงหาคม 2551` (มีรหัสนักศึกษา: `70301010001`)
3. **สถานะ "รอตรวจสอบ" (ปวช. เทคโนโลยีสารสนเทศ):**
   - เลขบัตร ปชช.: `1100400123453` | วันเกิด: `3 พฤศจิกายน 2553`
4. **สถานะ "เอกสารไม่ครบ / ให้ส่งแก้ไข" (ปวช. ช่างเชื่อมโลหะ):**
   - เลขบัตร ปชช.: `1100400123454` | วันเกิด: `17 กุมภาพันธ์ 2553` (สามารถทดสอบอัปโหลดเอกสารซ่อมได้ทันที)

## 🚀 ฟีเจอร์เด่นของระบบ

### ๑. ส่วนผู้สมัคร (Public Frontend)
- **หน้าแรก (Landing Page):** ดีไซน์โมเดิร์น สไตล์พรีเมียม โทนสีประจำวิทยาลัย น้ำเงินเข้ม (`#0B2A6F`), แดง (`#D91E18`), เหลืองทอง (`#F5B400`) รองรับมือถือเต็มรูปแบบ พร้อม Dark Mode
- **ฟอร์มรับสมัครแบบหลายขั้นตอน (Stepper Form):**
  - มี Progress Bar และระบบบันทึกร่างอัตโนมัติ (Auto-save draft) กู้คืนข้อมูลได้หากปิดเบราว์เซอร์
  - ตรวจสอบความถูกต้องของเลขบัตรประชาชน ๑๓ หลัก (Modulus 11 Checksum)
  - ระบบปฏิทินวันเกิด พ.ศ. มาตรฐานเดียวกันทั้งระบบ
  - ดรอปดาวน์ที่อยู่ไทยเรียงชั้น (จังหวัด → อำเภอ → ตำบล) ครบ ๗๗ จังหวัด และเติมรหัสไปรษณีย์อัตโนมัติ
  - ระบบเลือกสาขาวิชา: ปวส. เลือก ๑ สาขา / ปวช. เลือก ๒ ลำดับ (ตรวจสอบห้ามซ้ำกัน)
  - ตรวจสอบเกรดเฉลี่ยสะสม (GPAX 0.00–4.00)
  - อัปโหลดเอกสารหลักฐาน (JPG, PNG, PDF &le; 5 MB) พร้อมภาพตัวอย่าง (Preview) และลบ/เปลี่ยนไฟล์ได้
  - ยินยอมข้อตกลงคุ้มครองข้อมูลส่วนบุคคล (PDPA Consent)
  - ส่งสำเร็จแล้วออกเลขที่ใบสมัครทันที (เช่น `70-0031`) พร้อม QR Code และปุ่มดาวน์โหลด PDF ทันที
- **หน้าตรวจสอบสถานะ (/status):**
  - ค้นหาด้วยเลขบัตร ๑๓ หลัก + วันเกิด
  - Timeline แสดง ๔ ขั้นตอน (ยื่นใบสมัคร → ตรวจสอบเอกสาร → ผ่านคัดเลือก → มอบตัว)
  - กรณีเอกสารไม่สมบูรณ์ ระบุข้อความจากเจ้าหน้าที่ พร้อมช่องอัปโหลดเอกสารแก้ไข
  - ดาวน์โหลดใบสมัคร PDF และใบมอบตัว PDF เมื่อผ่านการคัดเลือก

### ๒. ส่วนเจ้าหน้าที่ / ผู้ดูแลระบบ (/admin)
- **แดชบอร์ดสรุปสถิติเรียลไทม์ (Live Analytics):**
  - การ์ดสรุป KPI: ผู้สมัครทั้งหมด, รอตรวจสอบ, เอกสารไม่ครบ, ผ่านคัดเลือก, มอบตัวแล้ว
  - กราฟแท่งแนวนอน (Horizontal Bar): ผู้สมัครแยกตาม ๑๓ แผนกวิชา
  - กราฟโดนัท (Donut Chart): แยกตามระดับ (ปวช./ปวส.สายตรง/ปวส.ต่างสาขา)
  - กราฟพื้นที่/เส้น (Area Chart): แนวโน้มยอดสมัครรายวัน
  - Top ๑๐ โรงเรียนเดิมของผู้สมัคร
  - สรุปแยกตามจังหวัดภูมิลำเนา และช่องทางที่รู้จักวิทยาลัย
- **ตารางจัดการผู้สมัคร (/admin/applications):**
  - ค้นหา กรองตามระดับ แผนกวิชา สถานะ เรียงลำดับ และแบ่งหน้า
  - ซ่อน/แสดงเลขบัตรประชาชน (PDPA Masking)
  - ดูรายละเอียดผู้สมัครและไฟล์แนบผ่านหน้าต่างพรีวิว
  - เปลี่ยนสถานะรายบุคคล (ระบุเหตุผล/เอกสารที่ต้องซ่อม) หรือเปลี่ยนสถานะกลุ่มพร้อมกัน
  - บันทึก Audit Log ทุกครั้งที่มีการเปลี่ยนสถานะ
  - พิมพ์ใบสมัครเดี่ยว และพิมพ์รวมหลายคนเป็นไฟล์เดียว (Batch PDF)
- **ระบบรับสมัคร Walk-in (/admin/walk-in):**
  - เจ้าหน้าที่คีย์ข้อมูลแทนผู้สมัครที่มาติดต่อด้วยตนเอง และพิมพ์ใบสมัครได้ทันที
- **ระบบมอบตัวนักศึกษาใหม่ (/admin/enrollment):**
  - บันทึกข้อมูลผู้ปกครอง พยาน วันที่มอบตัว
  - ออกรหัสประจำตัวนักเรียน/นักศึกษาอัตโนมัติ (เช่น `70201010001`)
  - พิมพ์ใบมอบตัวนักศึกษา PDF ทางการ
- **ระบบส่งออก Excel/CSV (/admin/export):**
  - สร้างไฟล์ `.xlsx` ตามมาตรฐานระบบงานทะเบียน ศธ.02
  - เลือกคอลัมน์ที่ต้องการส่งออกได้อย่างอิสระ
  - ป้องกันเลขบัตร ปชช. กลายเป็นตัวเลขทางวิทยาศาสตร์
- **ระบบตั้งค่า & แจ้งเตือน (/admin/settings):**
  - กำหนดปีการศึกษา ช่วงเวลาเปิด-ปิดรับสมัคร
  - กำหนดจำนวนรับโควตาของทั้ง ๑๓ แผนกวิชา
  - เชื่อมต่อและทดสอบ LINE Messaging API / LINE Official Account

### ๓. สเปก PDF ใบสมัครทางการ (ตรงตามแบบฟอร์มกระดาษ ๑๐๐%)
- ขนาด A4 แนวตั้ง ฟอนต์ไทย THSarabunNew
- ตราสัญลักษณ์วิทยาลัยมุมบนซ้าย (ไดคัทโปร่งใส)
- กรอบรูปถ่ายขนาด ๑ นิ้วมุมบนขวา (ฝังรูปที่ผู้สมัครอัปโหลด)
- ช่องติ๊ก ☑ ระดับการศึกษาที่สมัคร
- ข้อ ๑–๖ มีเส้นประ Dotted Leader ใต้ข้อความเหมือนแบบฟอร์มกระดาษ
- ติ๊กกำกับเอกสารหลักฐานที่ผู้สมัครแนบ
- จุดลงชื่อผู้สมัครและวันที่สมัครอัตโนมัติ
- แปลงตัวเลขเป็นเลขไทย (๑๒๓) และปี พ.ศ.
- มี QR Code ประจำใบสมัครเพื่อสแกนตรวจสอบสถานะ

8. แผนกวิชาการบัญชี

## 💻 วิธีการติดตั้งและรันโปรเจกต์ (Local Development)

### ข้อกำหนดระบบ:
- Node.js version 18 หรือ 20 ขึ้นไป
- npm version 9 ขึ้นไป

### ขั้นตอนการรัน:
```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. คัดลอก Environment File
cp .env.example .env.local

# 3. รัน Development Server
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## 🗄️ การตั้งค่า Supabase (PostgreSQL, Auth, Storage)

### ๑. สร้างโปรเจกต์บน Supabase:
1. เข้าไปที่ [supabase.com](https://supabase.com) แล้วสร้างโปรเจกต์ใหม่
2. ไปที่ **SQL Editor** แล้วคัดลอกคำสั่งจากไฟล์:
   - `supabase/schema.sql` (สร้างตาราง DDL, Indexes, RLS Policies)
   - `supabase/seed.sql` (สร้าง ๑๓ แผนกวิชา, ผู้ใช้เจ้าหน้าที่ และข้อมูลตัวอย่าง ๓๐ รายการ)
3. รันคำสั่ง SQL ทั้งสองไฟล์

### ๒. สร้าง Storage Bucket:
- ไปที่ **Storage** → สร้าง Bucket ชื่อ `application-files` (ตั้งค่าเป็น Private)

### ๓. นำ API Keys มาใส่ใน `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL="https://your-project.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="eyJhbGciOi..."
SUPABASE_SERVICE_ROLE_KEY="eyJhbGciOi..."
```

## ☁️ การ Deploy ขึ้น Vercel

1. Push โค้ดขึ้น GitHub Repository
2. ไปที่ [vercel.com](https://vercel.com) แล้ว Import โปรเจกต์
3. ตั้งค่า **Environment Variables** ใน Vercel Dashboard โดยคัดลอกจาก `.env.example`
4. กด **Deploy**
